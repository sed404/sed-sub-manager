# sed机场管理程序

基于 PHP + MySQL 的机场订阅管理程序，支持用户管理、卡密开通、代理管理、多线路订阅和在线套餐支付。

作者 QQ：78013314

## 功能介绍

- **用户管理**：用户注册、登录、到期时间管理、账号封禁与密码重置。
- **卡密管理**：批量生成卡密，配置有效期，支持兑换开通、续费、停用及使用记录查询。
- **代理管理**：管理代理账号、余额及卡密价格，代理可在独立后台生成卡密。
- **线路管理**：添加多条上游订阅，管理线路状态、排序、到期时间及流量信息。
- **节点管理**：同步解析节点，支持自定义名称、启停和排序。
- **多客户端订阅**：提供订阅链接及客户端导入入口，支持 Clash、Shadowrocket 等客户端。
- **套餐与支付**：配置在线套餐和支付宝支付，支持套餐开通与续费。
- **站点设置**：管理公告、软件下载信息、主题外观及订阅相关设置。
- **自动安装**：通过网页填写数据库信息并创建管理员账号，安装完成后自动锁定安装入口。

## 部署教程

### 1. 准备环境

- PHP 8.1 或以上版本。
- MySQL 5.7 / 8.0 或兼容数据库。
- PHP 扩展：PDO MySQL、cURL、OpenSSL、mbstring。
- 网站默认首页设置为 `index.php`，建议配置 HTTPS。

压缩包已包含 `vendor` 依赖目录，上传时请完整保留。

### 2. 创建数据库

在服务器管理面板中创建一个空数据库，记录数据库名称、用户名和密码。数据库用户需要具备建表、修改表及数据读写权限。

安装程序使用已创建的空数据库，不会自动创建数据库，也不会覆盖已有数据。

### 3. 上传程序

解压压缩包，将程序文件上传到网站根目录。安装期间允许 PHP 写入网站根目录和 `data` 目录。

使用 Nginx 时，在站点的 `server` 配置中加入以下规则，并保留原有 PHP 处理配置。以下正则规则应放在通用 PHP 正则规则之前：

```nginx
index index.php index.html;
autoindex off;
location ^~ /data/ { deny all; }
location ^~ /vendor/ { deny all; }
location ^~ /tests/ { deny all; }
location ~ /\. { deny all; }
location ~* ^/(config[^/]*\.php|composer\.(json|lock))$ { deny all; }
location ~* \.(sql|md|log|zip|lock)$ { deny all; }
```

### 4. 网页安装

打开网站域名，程序会自动跳转到 `/install.php`，依次填写：

- 数据库主机：通常为 `127.0.0.1`。
- 数据库端口：通常为 `3306`。
- 数据库名称、用户名及密码。
- 管理员账号：3–60 位字母、数字或下划线。
- 管理员密码及确认密码：12–72 字节，建议使用字母、数字和符号组合。

点击“开始安装”，程序自动创建数据表、管理员账号和数据库配置文件 `config.local.php`。安装完成后，进入 `/admin/` 使用刚设置的账号密码登录。

安装成功后，取消网站根目录的写权限，保留 `data` 目录的必要写权限。系统没有默认管理员密码。

### 5. 后台配置

1. 添加上游订阅线路并执行同步。
2. 按需设置节点名称、启停状态及排序。
3. 配置卡密、套餐和代理账号。
4. 如需在线支付，填写支付宝商户配置并完成支付流程测试。
5. 设置站点公告、软件下载信息及主题。

常用入口：

| 入口 | 地址 |
| --- | --- |
| 用户中心 | `/` |
| 管理后台 | `/admin/` |
| 代理后台 | `/agent/` |

### 6. 自动同步

在服务器计划任务中设置每五分钟执行一次：

```bash
php /你的站点路径/sync_upstreams.php
```

将路径替换为实际网站目录，实际同步频率由后台设置控制。

### 7. 维护与故障处理

- 安装失败时，检查 PHP 扩展、数据库信息及目录权限。若已留下部分表，修正问题后使用新的空数据库重试。
- 已安装站点不要重新运行安装程序；更新前备份数据库、`config.local.php` 和运行数据。
- 更换服务器时，迁移数据库及程序文件，并根据新环境调整数据库配置。
