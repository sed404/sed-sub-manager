# MoFa 共享节点订阅

一套基于 PHP、MySQL 和原生 HTML/CSS/JavaScript 的轻量订阅管理系统，可部署在常见的 LNMP/LAMP 环境中。

> 本项目只提供订阅、用户、卡密和订单管理能力。请在遵守所在地法律法规及上游服务条款的前提下使用。

## 功能

- 免费与付费用户注册、登录、封禁和套餐管理
- 卡密生成、激活、续费、代理余额与代理发卡
- Clash、小火箭、V2Ray、Surge 多客户端订阅入口
- 免费订阅开关、付费用户 24 小时拉取限制与风控提示
- 面向指定现有用户的订阅补偿活动
- 用户工单、截图上传、管理员回复与结束工单
- 公告、软件下载、登录页外观和手机卡活动管理
- 外部购买链接与支付宝当面付自由切换
- 支付套餐价格、名称、订阅天数和状态管理
- 支付宝 RSA2 验签、主动查单、异步通知和幂等到账

## 环境要求

- PHP 7.4 或更高版本，推荐 PHP 8.1+
- MySQL 5.7+ 或 MariaDB 10.3+
- PHP 扩展：`pdo_mysql`、`openssl`、`fileinfo`
- 使用支付宝支付时建议启用 `curl`
- Web 服务器需要允许 `data/` 下的图片读取，并禁止脚本执行

## 安装

1. 创建网站和一个空 MySQL 数据库。
2. 将源码上传到网站根目录。
3. 将 `config.example.php` 复制为 `config.php`。
4. 填写数据库名称、用户名和密码。
5. 设置至少 12 位的随机初始管理员密码。
6. 访问 `/admin/`，程序会自动创建数据表和管理员。
7. 登录后台完成订阅、公告、套餐和支付配置。

`config.php` 包含敏感信息，已被 `.gitignore` 排除，禁止提交到公开仓库。

宝塔等面板生成的 `.user.ini` 通常包含线上绝对路径，也已被排除。请在目标服务器上重新生成，不要从原站复制。

## 支付宝当面付

后台进入「支付」，将购买方式切换为「支付宝当面付」，然后填写：

- 支付宝开放平台应用 APPID
- 应用 RSA2 私钥
- 支付宝公钥
- 支付宝网关
- 套餐名称、价格和订阅天数

正式网关：

```text
https://openapi.alipay.com/gateway.do
```

沙箱网关：

```text
https://openapi-sandbox.dl.alipaydev.com/gateway.do
```

异步通知地址为：

```text
https://你的域名/alipay_notify.php
```

没有异步通知时，付款页仍会主动查询订单，但正式环境建议配置公网 HTTPS 通知地址作为到账兜底。

## 安全配置

Nginx 建议禁止数据目录执行脚本，并按实际需要限制目录访问：

```nginx
location ~* ^/data/.*\.(php|phtml|phar|cgi|pl|py|sh)$ {
    deny all;
}

location ~ /\.(?!well-known) {
    deny all;
}
```

生产环境还应：

- 强制启用 HTTPS
- 定期备份数据库，但不要把备份提交到 Git
- 使用独立且权限受限的数据库账号
- 妥善保管支付宝私钥并定期轮换
- 限制上传大小并保持 PHP/Web 服务器更新

## 开源仓库不应包含

- `config.php`
- 线上数据库导出
- 用户账号、Token、卡密和支付订单
- 支付宝密钥
- 用户上传的截图和工单附件
- ZIP/RAR 部署包和线上目录副本

仓库可以保留 `database.sql`，该文件只包含空表结构，不包含线上数据。

## 主要入口

- 用户中心：`/dashboard.php`
- 管理后台：`/admin/`
- 代理后台：`/agent/`
- 订阅接口：`/sub.php`
- 支付页面：`/pay.php`
- 支付宝通知：`/alipay_notify.php`

## 升级

覆盖 PHP 和静态资源文件即可。首次访问时 `init_db()` 会自动补建新表和字段。覆盖前请备份当前源码、`config.php` 和数据库。
